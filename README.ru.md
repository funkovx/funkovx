### ✦ Обо мне

Люблю делать то, чем сам пользуюсь каждый день: музыка играет с моего сервера Navidrome в macOS-клиенте, который я написал, а расписание пар приходит из парсера, который лежит у меня на хостинге. Основные системы — macOS и Arch с Hyprland.

- **DevOps:** Docker, Compose, Ansible, systemd, nginx
- **Инфраструктура:** мини-ПК на Proxmox (LXC, ВМ), VPS, Tailscale, self-hosted сервисы
- **Мониторинг:** Prometheus, Grafana
- **Сети:** OSPF, BGP, VPN, DNS, Wireshark
- **Безопасность:** CTF (web, forensics, OSINT)
- **Приложения:** бэкенды на FastAPI, нативные macOS-приложения (Northkov, Wallsy)
- **ИИ-агенты:** RAG, Langflow, интеграции с Claude
